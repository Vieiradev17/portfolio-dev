# 💻 Portfólio Profissional - Erik Vieira

> Website pessoal desenvolvido para apresentar meus projetos, habilidades técnicas e trajetória como Desenvolvedor Front-end.

💻 **Acesse a aplicação online:** [https://portfolio-devvieira.netlify.app](https://portfolio-devvieira.netlify.app)

---

## 🚀 Sobre o Projeto

Este portfólio foi criado para centralizar minhas principais aplicações web e projetos comerciais. Desenvolvido com foco em usabilidade, responsividade e apresentação clara das minhas competências na área de tecnologia.

---

## ✨ Principais Funcionalidades

- **Apresentação Pessoal:** Seção sobre minha trajetória, foco de carreira e qualificações.
- **Galeria de Projetos:** Exibição das aplicações desenvolvidas com links diretos para visualização.
- **Seção de Habilidades (Skills):** Destaque para as tecnologias que utilizo no dia a dia.
- **Links de Contato:** Acesso direto ao GitHub, LinkedIn e formulário/meios de contato.
- **Layout Responsivo:** Adaptado para navegação fluida em celulares, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript
- **Hospedagem:** Netlify

---

## 🚀 Como Executar o Projeto Localmente

1. **Faça o download do repositório:**
   Clique no botão **Code > Download ZIP** no topo da página.

2. **Abra o projeto:**
   Extraia os arquivos e abra o arquivo `index.html` em qualquer navegador.
